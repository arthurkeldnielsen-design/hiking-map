# Hiking Map

An interactive web-based hiking trail map. No downloads required—just open in your browser!

## Features

- 🗺️ Interactive map with hiking trails
- 📍 Trail markers and information
- 🌲 Fully browser-based (no server needed)
- 📱 Mobile-friendly responsive design
- 🚀 Hosted on GitHub Pages

## Quick Start

Visit the live website: [Your Website Here]

Or run locally:
1. Clone this repository
2. Open `index.html` in your browser
3. Explore the trails!

## How to Add Trails

Edit `data/trails.json` to add new hiking trails with coordinates, descriptions, and difficulty levels.

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla)
- Leaflet.js (for maps)
- OpenStreetMap (free map tiles)
